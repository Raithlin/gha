# v0.3.0-alpha

This alpha adds guarded release publication. `gha release publish` checks the selected commit, origin branch tip, existing tags, CI, and the tag-triggered workflow before showing the planned tag effects and requiring explicit confirmation.

## Changes

- [#9](https://github.com/Raithlin/gha/pull/9) adds the release publication workflow and updates the roadmap.
- [#8](https://github.com/Raithlin/gha/pull/8) updates `dependabot/fetch-metadata` from v2 to v3.

The release also includes the [95% total statement coverage gate](https://github.com/Raithlin/gha/commit/a9c61c9d6080f86c5d75fddf4ca3472919aa9433), supporting tests, and release and token-access documentation updates.
